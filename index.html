stream ・ 直播 / 电台播放台

终端 stream 命令的网页异构版 —— 同一份菜单，点击即弹出独立播放窗口
无地址栏：虎牙 / 抖音 / 电台一律弹窗播放，效果等价终端版的 mpv 窗口

← 返回档案首页

选择主播 / 电台（键盘 1–6，点击即弹窗播放）

与终端版 menu 顺序一致 · 同名窗口自动复用 · 支持深链如 #suk / #radio
点击上方任意一项，将弹出一个无地址栏的独立播放窗口。

说明

  • 弹窗即播：虎牙 / 抖音 / 电台一律在独立窗口中播放官方网页播放器，窗口尺寸铺满屏幕、隐藏地址栏与工具栏；关闭本页不影响播放窗口，再次选择同一项会复用已有窗口。
  • 电台 FM91.4：radio5.cn 官方播放器，进窗口后点一下它自带的播放键即可（浏览器自动播放策略限制）。
  • 弹窗被拦截：请允许本站弹窗（点菜单时会即时弹出）；若被拦截，下方状态栏会给出直达链接。
  • 断流恢复：各官方播放器自带重连；终端版 streamlink + mpv 的重连逻辑不适用于网页版。
