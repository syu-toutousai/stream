知っておいてほしいこと

  • 窓を開けば、そのまま流れる：虎牙・抖音・音の流れ・YouTube は、どれも別の窓で流れます。この頁を閉じても流れは止まりません。同じものを選び直すと、開いている窓をそのまま使います。
  • 色の意味：青はいつでも見られるもの（VOD、8 / あ / う / え）で、確かめません。緑はいま見られる生、灰はいまは見られない生、黄は生だが、この場からは確かめられないものです。ブラウザの仕組みで他の場所の中身は読めないため、自動で確かめられるのは NHK と ゆめのたね だけです。ほかの生は窓を開いて確かめてください。「確かめ直す」でまた確かめられます。
  • 音の流れ：FM91.4 は radio5.cn の本家の窓（中国の時計で 01:00–06:00 は休み）。NHKワールド・ラジオ日本 はこの場の HLS の窓（本家 r1 の流れ → media2 の控え）。ゆめのたね放送局 はこの場の六つの色の窓で、色を押すとその場で切り替わります。
  • YouTube：8 / あ / う / え は、その人が上げたものの並びから、はじめに一つを気まぐれに選んで流します（「🔀 選び直す」で別のものを選べます）。お は TBS NEWS DIG の一日中の生。ウェブ版は並びを貯めず、どこまで見たかも覚えません（それは文字の画面版の yt-dlp の仕事です）。
  • 地蔵菩薩本願経：1998年の浄空法師の講義、全51巻。ウェブ版だけの聞きもので、章一覧から巻を選ぶと、その巻の動画が開きます。いつでも見られるもの（VOD）です。
  • 窓が開かないとき：この場で窓を開けることを許してください。開かないときは、下の帯に「もう一度押す」と「本家の頁」が出ます。
  • 流れが切れたとき：本家の窓はひとりでにつなぎ直します。ゆめのたね は切れたら ▶ の印を押せばつながります。文字の画面版の streamlink + mpv のつなぎ直しは、ウェブ版にはありません。
