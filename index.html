选择主播 / 电台 / 日语节目（键盘 1–9 / あ–お / 0，点击即弹窗播放）

与终端版 menu 顺序一致 · 同名窗口自动复用 · 深链 #suk / #radio / #nhk / #ynt-red
点击上方任意一项，将弹出独立播放窗口；深链 #radio 打开潮州 FM91.4。

说明

  • 弹窗即播：虎牙 / 抖音 / 电台 / YouTube 一律在独立窗口中播放；关闭本页不影响播放窗口，再次选择同一项会复用已有窗口。
  • 电台：FM91.4 使用 radio5.cn 官方播放器（北京时间 01:00–06:00 停播）；NHKワールド・ラジオ日本 使用本站 HLS 播放窗口（官方 r1 主源 → media2 备用流）；ゆめのたね放送局 使用本站六色播放窗口，直连 CloudFront 官方流，点颜色即换台。
  • YouTube：选项 8 / あ / う / え 用内嵌播放器从频道上传列表中随机开始，可点「🔀 シャッフル」重新打乱；选项 お 为 TBS NEWS DIG 24 小时直播。网页版不缓存视频列表，也不保存播放进度（这些是终端版 yt-dlp 的功能）。
  • 弹窗被拦截：请允许本站弹窗（点菜单时会即时弹出）；若被拦截，下方状态栏会给出「再点一次播放」按钮和直达链接。
  • 断流恢复：官方播放器自带重连；ゆめのたね 断流后点一下播放键即可重新连接；终端版 streamlink + mpv 的重连逻辑不适用于网页版。
